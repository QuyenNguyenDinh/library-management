# Hệ thống quản lý mượn sách thư viện — Nhóm 04

Đồ án Java OOP: Spring Boot (backend) + React (frontend) + file JSON (mock database).

## Chạy backend
Cần Java 21. Không cần cài Maven.

```bash
cd backend
mvnw.cmd spring-boot:run     # Windows  → http://localhost:8080
./mvnw spring-boot:run       # macOS/Linux
mvnw.cmd test                # chạy test
```

## Chạy frontend
Cần Node.js 20+.

```bash
cd frontend
npm install
npm run dev                  # → http://localhost:5173
```
